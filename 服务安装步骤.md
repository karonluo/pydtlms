# DTLMS 服务安装步骤

## 安装组件

### 安装 git

```bash
apt -y install git
```

### 克隆代码

```bash
git clone https://github.com/karonluo/pydtlms.git
cd pydtlms
```

### 构建 python3 虚拟环境

```bash
python3 -m venv .venv
```

### 进入 python3 虚拟环境

```bash
source .venv/bin/activate
```

### 安装 python3 插件/组件库

```bash
cd ~/pydtlms/backend
python3 -m pip install -r ./requestment.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 安装 nodejs

```bash
curl -sL https://deb.nodesource.com/setup_20.x |bash
apt -y install nodejs
```

### 更新 nodjs & npm

```bash
npm install -g npm@latest
```

### 安装 nodejs 插件/组件库

```bash
cd ~/pydtlms/frontend
npm install
```

## 启动服务

### 启动后端服务

**注意：这里若没有进入 Python3 虚拟环境，先需要进入 .venv 虚拟环境，前面安装步骤中有相关命令。**

```bash
cd ~/pydtlms/backend
nohup ./run.sh > run.log &
```

### 配置 Nginx

```bash
vim /etc/nginx/nginx.conf
```

#### 配置文件内容 (注意这里是生产正式环境的配置，其他环境根据具体情况自行修改)

```nginx
user  www www;
worker_processes  auto;

error_log  /var/log/nginx/error.log;
pid        /usr/local/nginx/logs/nginx.pid;

events {
    worker_connections  1024;
}

http {
    include       mime.types;
    default_type  application/octet-stream;
    sendfile        on;
    keepalive_timeout  65;

    server {
        listen 80;
        server_name admissions.pjlab.org.cn;
        return 301 https://$server_name$request_uri;
    }

    server {
        listen 443 ssl;
        server_name admissions.pjlab.org.cn;
        ssl_certificate      /usr/local/nginx/conf/ssl/pjlab.org.cn.pem;
        ssl_certificate_key  /usr/local/nginx/conf/ssl/pjlab.org.cn.key;
        ssl_session_timeout 5m;
        ssl_ciphers ECDHE-RSA-AES128-GCM-SHA256:ECDHE:ECDH:AES:HIGH:!NULL:!aNULL:!MD5:!ADH:!RC4;
        ssl_protocols TLSv1 TLSv1.1 TLSv1.2;
        ssl_prefer_server_ciphers on;
        root /usr/local/nginx/html/dist;
        index index.html;
        client_max_body_size 50m;
        access_log /var/log/nginx/pjlab-access.log;
        error_log /var/log/nginx/pjlab-error.log;
        location /api/v1/ {
            proxy_pass http://127.0.0.1:8000/api/v1/;
            proxy_http_version 1.1;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
        }
        location /assets/ {
            try_files $uri =404;
        }
        location /recruitment/news/uploads/ {
            proxy_pass http://127.0.0.1:8000/recruitment/news/uploads/;
            proxy_http_version 1.1;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
        }
        location / {
            try_files $uri $uri/ /index.html;
        }
    }
}
```
